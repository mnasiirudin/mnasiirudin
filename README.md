## 🚀 Proyek Unggulan

*   **STM32 Line Follower Robot:** Pengembangan PCB *minimum system* untuk robot *line follower* 14-sensor, ditenagai STM32F103 dengan *impeller suction fan* dan *driver* DRV8833.
*   **3-Wheel Kiwi Omni-Drive:** Desain sasis robot *omni-drive* roda 3 beserta algoritma kinematika pergerakan dan integrasi kontrol Bluetooth.
*   **Smart Incubator Multifungsi:** Sistem inkubator cerdas berbasis ESP32 menggunakan logika PID untuk kontrol suhu, *switching* SSR, dan pemantauan jarak jauh via Blynk.
*   **Z80 Microprocessor Minsys:** Desain skematik dan simulasi *board minimum system* Z80 yang mengintegrasikan *memory decoding* dan ekspansi periferal 82C55 PPI.
*   **RFID Vehicle Security Gate:** Implementasi gerbang keamanan otomatis yang menggabungkan *reader* RFID UHF HW-VX6330K, ESP32, motor *stepper*, dan antarmuka manajemen web.
